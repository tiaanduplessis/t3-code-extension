# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub: open the repository's **Security** tab and choose **Report a vulnerability**. Do not open a public issue for security problems.

Include what you found, how to reproduce it, and the versions of the extension, Chrome and T3 Code you used. You will get an acknowledgement when the report has been read. This is a personal project maintained in spare time, so there is no fixed response time.

## Supported versions

Only the latest release receives fixes.

## Scope

Reports are most useful for problems in this extension. Examples:

- exposure of the stored T3 Code connection tokens
- the `Origin` header rule applying to requests other than the extension's own
- page or Slack content reaching T3 Code without the user sending it

Vulnerabilities in T3 Code itself belong to the [T3 Code project](https://github.com/pingdotgg/t3code).
